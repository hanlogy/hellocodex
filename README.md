# Hello Codex website

The home page of Hello Codex, served by GitHub Pages from this repository.

It's one static page, `index.html`, with its images in `images/`. The empty
`.nojekyll` file makes GitHub Pages serve the files as they are, without
running them through Jekyll. To preview it locally:

```sh
python3 -m http.server 8000
```

Then open http://localhost:8000.
